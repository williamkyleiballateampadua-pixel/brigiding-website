# Git Branch Naming Conventions

Always use the **Category/Ticket-Description** pattern for Git branches:
- `feature/` (or `feat/`): New features or enhancements (e.g., `feature/express-rest-api-domains`)
- `bugfix/` (or `fix/`): Standard bug resolutions (e.g., `bugfix/env-parser`)
- `hotfix/`: Urgent, production-blocking fixes (e.g., `hotfix/security-patch`)
- `chore/`: Routine tasks like updating dependencies, documentation, or tooling config (e.g., `chore/update-readme`)
- `refactor/`: Code refactoring without changing functionality (e.g., `refactor/api-response-format`)
